# The Absurd Clause Contest

One sentence, an absurd clause hidden deep inside a terms-of-service agreement, written by a small deterministic program.

> The Company reserves a non-exclusive, perpetual license to the User's shadow for marketing purposes, including use in any medium now known or hereafter invented.

`main.ts` writes that clause (161 characters) to `/output/entry.txt`. No network, no dependencies, no secrets — just Node's standard library.

Entered in [The Absurd Clause Contest on make.fun](https://make.fun/c/u-donrulezz-the-absurd-clause-contest-035cc0f1).
